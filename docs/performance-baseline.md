# 接口性能基线

本文件按测试轮次追加接口性能数据，用于后续发现性能退化。当前阶段只积累基线，不设性能通过/失败阈值，也不把单次结果解释为上游 SLA。

## 测量与追加约定

- **网络抓取时间**：从发起上游请求到收到并解析响应的耗时；成功率与失败耗时单独记录，失败响应不计入正常抓取性能。
- **计算时间**：本地数据加工、聚合和指标计算的耗时；复杂计算应逐步拆分 SQL、Python 和字典读取时间。
- **查询响应时间**：调用 `tools_*` 公共接口到返回结果的端到端耗时，包含数据库查询；测试数据准备、一次性建表和种子写入不计入。
- 平均值为算术平均。每轮必须记录时间、环境、场景、样本量和成功率；后续增加 p50/p95，不用单次均值设门禁。
- 每轮测试在文件末尾追加 `---` 和时间标题，**只写本轮实际测量的接口**，不保留“待测”占位行，未涉及的接口不出现在该轮记录中。
- 历史轮次只追加、不覆盖。原始数据可留本地，趋势摘要定期回写 #131。
