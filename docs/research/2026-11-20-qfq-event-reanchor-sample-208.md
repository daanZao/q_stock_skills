# baostock qfq 初始化与事件重锚样本（#208）

日期：2026-11-20（Asia/Shanghai）。范围：20 只代表股票，2005-01-01 至 2026-11-20 请求窗口的 qfq/raw，以及 1990-01-01 至同一截止日的单票因子。本文只代表本轮静态样本，不代表长期可用性、全市场完备率或生产切读结论。

## 0. 结论先行

1. **20/20 股票、60/60 逻辑查询最终成功**。qfq 与 raw 各 70,358 行，因子 350 行；qfq/raw 日期逐票完全对齐。实际最后交易日多为 2026-11-19，退市 600200 止于 2025-12-30，000016 止于 2026-10-22。
2. **实际 qfq 价格是 10 位小数，raw 是 4 位**。这修正了 #206 / ADR 0021 原先的“上游四位小数”假设。OHLC/preclose 无空值；volume/amount/pctChg 各 68 个空值，turn 2,483 个空值，qfq/raw 空值位置一致。
3. **直接 qfq 精确等于 `raw × 对应 foreAdjustFactor`**。20 只股票、351,790 个 OHLC/preclose 值全部零差异；volume、amount、turn、tradestatus、pctChg、isST 在 qfq/raw 间无数值差异，最新事件段 qfq=raw 也无例外。
4. **back-only 自动重锚不安全**。000001、000002 的 back 在部分日期下跳/恢复而 fore 不变；`B_prev/B_cur` 会把这些行解释成价格事件。back 闭式解全样本 P95 绝对差为 0.424140 元，最大 3.168256 元；不能靠统一放宽容差解决。
5. **fore 比值逐事件重锚高度吻合直接 qfq**。从 raw 起按 `fore_prev/fore_cur` 逐事件更新事件日前价格，并在每次更新后保留 10 位小数，351,790 个价格值最大绝对差 `7E-10` 元，P95=`1E-10`、P99=`3E-10`，最大相对差 `3.8136971E-10`。
6. **需要 Spec 纠偏而非静默换公式**：#222 待用户确认“fore 主口径 + back 交叉核验”及不一致时的 pending/告警语义；在 #222 关闭前，#212 自动事件实现保持 native blocked。#210/#211 初始化和 raw_identity 不受影响。

## 3. 字段、精度与空值

### 3.1 直接观察

- qfq 的 OHLC/preclose 均观察到 10 位小数，raw 均为 4 位；例如 600519 在 2005-01-04 的 qfq close=`7.7283112500`，raw close=`36.4500`。
- qfq 行 `adjustflag=2`，raw 行 `adjustflag=3`；amount 保留上游元值，未做库内万元转换，volume 为股。
- qfq/raw 每只股票日期集合完全一致，没有 qfq-only 或 raw-only 日期。

## 4. 分析方法

### 4.1 直接公式

对每个交易日 t，取 `dividOperateDate<=t` 的最后一条因子；没有则 fore/back 基值取 1：

```text
fore_expected(t) = raw(t) × fore(t)
back_expected(t) = raw(t) × B(t) / B_latest
```

直接 fore 公式检查 OHLC/preclose 五列；back 闭式解统计 close，并另外模拟逐事件 back 重锚。

### 4.2 逐事件模拟

每只股票从样本内 raw 价格起步，按事件日期顺序处理。首个事件之前的 fore/back 前值取 1；样本首日及以前事件只推进前值，不修改样本内价格：

```text
f_back = back_prev / back_cur
f_fore = fore_prev / fore_cur

t < D：price(t) = round10(price(t) × f)
t ≥ D：price(t) 不变
```

该过程刻意在每次事件后保留 10 位小数，模拟实际物化 qfq 表的逐次舍入，而不是只做一次高精度闭式计算。fore 模拟检查全部 351,790 个 OHLC/preclose 值。

## 5. 误差结果

### 5.1 fore：直接精确，逐事件仅有 10 位末位差

| 指标 | 直接 raw×fore | fore 逐事件 + 10 位舍入 |
| --- | ---: | ---: |
| 价格值数 | 351,790 | 351,790 |
| 非零差值数 | 0 | 124,080 |
| 最大绝对差 | 0 | 7E-10 元 |
| P95 绝对差 | — | 1E-10 元 |
| P99 绝对差 | — | 3E-10 元 |
| 最大相对差 | 0 | 3.8136971E-10 |

这是本轮最强的算法证据：上游 qfq 的段乘数就是 fore；fore 比值递推能复现直接 qfq，差异只在第 10 位小数附近。

### 5.2 back：正常段尾差与异常段大偏差必须分开

全部 70,358 个 close 的 back 闭式解：

- P50=0.000003398 元；P95=0.424140 元；P99=1.875441 元；最大 3.168256 元。
- 仅 87.562% 的行绝对差不超过 0.001 元。
- 剔除 000001/000002 后，其余 18 只、59,732 行的 P99=0.000357814 元，最大 0.000828689 元，全部不超过 0.001 元。

因此“18 只尾差很小”和“2 只存在结构性反例”必须同时报告。把两只异常股纳入同一个宽阈值，会掩盖错误公式；把它们剔除后宣称全样本通过，也不允许。

### 5.3 具体反例

**000001 / 2020-12-31**：

```text
back: 119.960317 → 99.787353，f_back=1.202159526
fore: 0.781647 → 0.781647，f_fore=1
```

2020-12-01 raw close=20.05，直接 qfq close=15.6720223500，恰为 `20.05×0.781647`；back 闭式解却为 18.8402784359，差 -3.1682560859 元。2021 年起该股票样本内 back 闭式差又回到很小的尾差，说明问题是特定因子段，不是全序列统一缩放。

**000002 / 2020-11-16、11-19、11-20 与 2025-01-09**：

- 2020-11-19 back 从 115.094135 降至 112.152874，次日恢复；fore 始终 0.846987。
- 2025-01-09 back 从 135.886551 降至 134.284605，fore 始终 1。
- 这些行的 back 比值会产生约 0.6%–2.6% 的额外历史乘算，而 fore 比值为 1，直接 qfq 不需要该阶跃。

按 `abs(f_back-f_fore)/f_fore>0.0001` 的审计口径，本轮共 16 行，全部位于 000001（11 行）和 000002（5 行）；其中也包含早期历史事件，说明该清单用于归因，不应直接当成未来每日告警阈值。

## 6. 容差建议（未批准）

以下只是本轮样本导出的候选，不是 #206 已批准验收线：

1. **直接初始化 qfq 对账**：在本样本精度下，`raw×fore` 可做精确 Decimal 等值检查，不需要误差阈值。
2. **fore 逐事件本地重锚**：若实现按 10 位小数逐次舍入，可暂以 `abs error≤1E-9 元` 且 `relative error≤1E-9` 作为候选回归线；它覆盖本轮最大 7E-10 和 3.8137E-10，但仍需更多事件与全字段样本后由用户批准。
3. **back/fore 不一致**：不建议简单设一个宽容差继续 back 自动重锚。候选实现是 fore 为主、back 交叉核验；不一致时进入 pending 还是只告警，由 #222 决策。
4. **不采用 back-only 统一容差**：000001 的最大相对差约 32.24%，000002 也有多段持续偏差，已不属于“尾差”。
