# ADR 0015：龙虎榜历史 basic 采用同花顺市场级后备，真实对拍前默认关闭

Status: superseded by ADR-0016（仅深圳历史 `lhb_basic` 的主源与默认启用决策；其余默认关闭阶段机制保留）

2026-10-27，issue #126/#127（父需求 #125）。

## Context

- 历史回溯与统计前置 staging 要求当日 basic 完整；交易所官方任一市场连接失败，现有 `partial_error` 会保留旧日并中止 staging。通用 fallback 链无法处理官方“部分市场成功”，因为部分成功不会触发下一适配器。
- 同花顺历史日期页一次提供沪深北股票、逐原因榜单与买卖汇总，可作 basic 后备；但 HTML 契约、字段口径与历史名称仍需和官方源对拍，且同源风控敏感。

## Decision

- 保留交易所官方主源。仅历史回溯及统计前置 staging 在显式 `--fallback ths` 时启用同花顺；单日、`close` 与 `--check` 不启用，默认链不变。
- 官方按市场失败时，只从同花顺当日结果补失败市场，保留其他市场官方行；官方正常空日不触发后备。合并后仍复用 basic 按日原子替换与近 60 日历日 statistic 重算。
- 后备只承载 `lhb_basic`，不承接两个营业部累计榜；不新增 basic 来源列。实际主源、补缺源、市场和行数进入结构化响应及采集台账。
- 每个历史日期最多一次页面请求，日期间 20 秒长退避；403/封禁页后停止本轮后续日期，不做同源自动重试，不逐股请求。
- 金额统一万元，`total_amount=buy+sell`；净额与买卖差额按页面单位舍入精度校验。`day_amount` 仅作对拍元数据，三日/异常期间累计行置空；`turnover_rate` 无独立实际值时置空。
- 本 ADR 只批准默认关闭的第一阶段能力。深交所恢复并完成官方—同花顺真实对拍后，才能另行决定加入默认历史链。

## Consequences

- 官方单市场或三市场同时故障均可在显式开启后完成历史补缺，混合来源不再被静默记成纯官方数据。
- 同花顺 HTML 解析由录制 fixture 固定；万元/亿元及独立净额舍入差按页面精度处理。异常 HTML、日期错位、业务键重复与净额异常均拒绝作为完整后备输入。
- #127 已补全复杂页面边界与完整失败语义；第一阶段完成仍不等于生产默认链已验收，默认启用由 #128 真实对拍后单独承接。
