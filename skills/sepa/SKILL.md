# SEPA 方法论

Minervini SEPA 框架的 A 股分析指引。本 skill 为方法论 skill，主体是**判断逻辑**；指标计算一律调用 `indicator-tools`（工具函数 skill，不内嵌实现），数据一律来自 MCP 工具（`query_daily`、`get_fundamentals`），不直接访问数据库。`query_daily` 输出结构为跨仓库稳定契约，见 ADR 0001（`docs/adr/0001-mcp-server-boundary.md`）。

核心哲学：只做 Stage 2（上升阶段）的市场领导者；只在 VCP 突破枢轴点时入场；7-8% 硬止损；拒绝抄底、拒绝弱势股、拒绝无催化剂交易。

## 输入契约（取数链路）

1. **日线数据**：MCP `query_daily(stock_code, days=400)`（adj 用默认 `qfq` 前复权；需 ≥250 个交易日以覆盖 200 日线与 52 周窗口；400 根同时保证 EMA 收敛）。`query_daily` 库内缺数据自动补抓（自愈），无需单独补抓步骤。**`count < 250` 时明确报告数据缺口并终止，不硬算**；`status != ok` 时如实转述错误，不拿旧数据充数。
2. **指标结果**：将 `query_daily` 的 JSON 输出作为 stdin 管道给 `indicator-tools` 的 `scripts/indicators.py`（指标口径与边界规则见该 skill，此处不重复）：
   - `ma --periods 5,10,20,50,150,200`（趋势模板、均线排列）
   - `macd`（动量辅助：0 轴上方运行、死叉次数）
   - `rolling_max`/`rolling_min --window 250`（52 周高/低点）
   - `maxdd --window 250`（最大回撤）
   - `chg --window 250`（个股 250 日涨幅；与沪深300 同期对比得 RS 近似，指数基线取法见第 4 条）
   - `ma --on volume --periods 20`（20 日均量，VCP 量能判断）
   - `diff1 --on ma200`（200 日线方向判断，判定口径见判断逻辑第一/二步）
   - 指标返回 `insufficient_data` 时按数据缺口处理（加大 `days` 重新 `query_daily` 后重算；仍不足则报告缺口）。
3. **基本面数据**：MCP `get_fundamentals(stock_code)`（proxy 透传，字段名保留上游，需自行解读）。需要：最近 4 个季度 EPS、营收、毛利率、扣非净利润、ROE。各数据源 section 不同（akshare：`financial_abstract`/`valuation_indicator`；efinance：`base_info` 基础信息快照；baostock：`profit`/`growth` 单季），`data` 中可能带 `errors` 键列出失败 section。**`status=error`（全部数据源失败）或所需字段缺失时，E 维度明确降级标注缺失，不臆断计分，绝不编造**（计分口径见输出契约第 3 条）。
4. **指数基线**：沪深300 等指数日线不在 `query_daily` 覆盖范围（仅个股）。RS 对比与大盘阶段判断的降级路径：`query_board_data("market_indices")` 盘面指数快照做近期表现近似（该表为盘面落库数据，查不到时先 `fetch_board_snapshot` 补抓当日盘面）；需要指数 250 日序列而无法经 MCP 获得时，RS 与大盘阶段标注"近似/降级"并说明置信度影响。
5. **催化剂/风险信息**：近期公告、新闻（会话中由用户提供或检索获得；不可得则标注缺失）。

## 判断逻辑（按顺序执行，任一否决即终止）

### 第一步：阶段分析（Stage Analysis）—— 第一否决权

Weinstein 四阶段，只做 Stage 2。Stage 2 判定（须全部满足）：

1. 价格高于**上升中的** 200 日均线（`diff1 --on ma200` 近 30 日均值为正）
2. 价格高于 150 日线，且 150 > 200
3. 价格高于 50 日线，且 50 > 150 > 200
4. 价格结构呈现更高的高点与更高的低点
5. 相对强度 RS ≥ 70（个股 250 日涨幅位于市场前 30%；用 `chg` 与指数基线对比近似，降级时标注）

Stage 1/3/4 或 200 日线走平向下：**一票否决，输出"放弃"并终止**。

### 第二步：趋势模板八条铁律（缺一不可）

1. 现价 > 150 日线；2. 现价 > 200 日线；3. 150 日线 > 200 日线；4. 200 日线向上（高于 30 天前）；5. 50 日线 > 150 且 > 200；6. 现价 ≥ 52 周低点 × 1.3；7. 现价 ≥ 52 周高点 × 0.75；8. RS ≥ 70。

任一 Fail → 不得买入，终止分析。

### 第三步：四要素深度分析

- **S 入场点**：识别 VCP——Stage 2 中的整理基部，2-6 次回调且波动率递减（如 -20%→-12%→-6%），回调缩量、反弹温和放量；枢轴点 = 最终收缩区最高价 + 0.5~1% 缓冲；触发 = 突破枢轴点且当日量 ≥ 20 日均量 140-150%。三种入场路径：A 标准突破（50-100% 目标仓位）；B 预期性入场（供应枯竭、突破前试探 25-50%）；C 突破后 3-5 日内健康回踩 10/20 日线且未破枢轴（补票加仓）。首次突破失败（放量滞涨/长上影/次日收阴破枢轴）则该基部作废。
- **E 盈利**：季度 EPS 同比 ≥20%（理想 ≥40-50% 且加速），营收同比 ≥15%（理想 ≥25% 且加速），利润率稳定或扩张，ROE ≥17%；加速 = 最近 3 个季度 EPS 同比递增；QoQ 优秀为加分。A 股辅助：归母净利润环比趋势与同比方向一致；警惕季节性（Q1 环比 Q4 允许回落）。**数据不可得则该维度标注缺失，不按满分也不按零分臆断**。
- **P 价格行为**：趋势模板（第二步）+ RS Rating 分级（90-99 S 级 / 80-89 A / 70-79 B / 50-69 C / <50 D 一票否决）+ 动量健康度（最大回撤 ≤15%、收益/回撤 ≥2:1 为健康；回撤 >35% 否决；连续 20 日新高 ≥5 次为动量透支）+ VCP 结构质量 + 杯柄形态（杯底→回踩 20 日线确认→放量突破杯口，为重大机会信号）。MACD 参考：0 轴上方运行、本轮 0 轴上方死叉 <3 次为佳。
- **A 催化剂**：新产品/重大合同/监管批准/行业政策/业绩窗口/管理层变动；无明确催化剂 → 仓位减半或观望；催化剂与盈利共振最佳。

### 第四步：风险管理铁律

- 技术止损：VCP 最后收缩低点下方 1-2%（风险 3-5%）；绝对硬止损：入场价下方 7-8%；时间止损：5-10 个交易日未脱离入场区 3% 主动减仓。
- 头寸：单笔风险 ≤ 账户 1.25-2.5%；仓位 = 风险预算 ÷（入场价-止损价）。渐进暴露：先试 50%，站稳枢轴加满，入场日收阴/破枢轴/放量滞涨立即砍。
- 退出：盈利 20-25% 卖 1/3；盈利 10-15% 后止损移至成本；剩余用 10 日线/21 日 EMA 跟踪，收盘跌破清仓；确认进入 Stage 3 全部离场。禁止固定目标价、禁止等到跌破 100 日线才离场、禁止亏损加仓。

### 第五步：市场环境过滤

大盘（沪深300/上证）需处于 Stage 2 或至少高于 200 日线。指数历史序列不可经 MCP 获得时，用 `query_board_data("market_indices")` 快照做近似判断并标注降级（见输入契约第 4 条）。大盘 Stage 4：仓位减半或空仓；大盘横盘：只参与 RS 90+ 且止损收紧至 5%。

## 输出契约（结构化结论）

输出 markdown 报告，固定章节：

1. **阶段判定**：Stage X、200 日线方向、均线排列、通过/否决
2. **趋势模板检查**：8 条逐条 Pass/Fail 及数值
3. **SEPA 评分（48 分制）**：S(10) + E(13) + P(15) + A(10)；≥40 强烈买入 / 32-39 买入 / 24-31 观察等待 / <24 放弃。某维度数据缺失时**该维度不计分**（既不按满分也不按零分臆断），注明缺失维度、实际计分口径（如"E 缺失，总分 38/35 可评维度"）及置信度影响
4. **E 盈利深度分析**（数据缺失时明确标注，不编造）
5. **P 价格行为与动量验证**：RS 分级、区间收益、最大回撤、VCP 结构（收缩次数/波动率递减/枢轴点价/量能）、杯柄形态
6. **交易计划**：触发价、止损价、部分止盈、移动止损、建议仓位、入场路径
7. **市场环境**：大盘阶段与对仓位的影响（近似判断需标注）
8. **风险排查**：减持/预亏/监管/解禁/政策利空、估值状态
9. **最终结论**：强烈买入/买入/观察等待/放弃；明确 stage 类型与所处位置、推导依据；"观察等待"须列出后续观察要点
10. **数据缺口声明**：逐项列出缺失/降级数据（基本面 section、指数基线、催化剂等）及其对结论可信度的影响

**数据缺失红线**：关键数据（日线、基本面）无法获得时，结论中明确标注缺失项及其对结论可信度的影响，不得编造数据补齐分析。

**结论持久化（可选）**：最终结论可经 MCP `save_conclusion(subject_type="stock", subject_code=<代码>, trade_date=<交易日>, conclusion_type="sepa.full", payload=<结论 JSON>)` 落库；payload 结构由本 skill 自行约定，同键重复写入为 upsert。
